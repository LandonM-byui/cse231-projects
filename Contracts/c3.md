## My learning plan

1. Review the WDD 231 Competency Guide's Responsive CSS and inclusive visual design section. Check the current page at a narrow viewport and record one specific layout or usability problem.
2. Represent participants and first-round matchups as JavaScript data. Create a rendering function that builds the repeated matchup content, and separate it from the event handler that collects participants and triggers rendering.
3. Split the data or rendering code into modules if that makes their responsibilities clearer. Use meaningful anchors for page navigation and keep buttons for actions such as generating the bracket.
4. Apply a mobile-first layout to the participant form and bracket. Check readable text, contrast, spacing, and usable control sizes; decide how the bracket will reflow or scroll on a narrow screen.
5. Test with different participant counts, including an odd number, and verify the layout at narrow and wide viewport sizes. Record one problem, my hypothesis, the fix, and how I checked it.
